## 已实施及关键边界

- 一个自然 Markdown 流式 Agent 处理记录、提问和混合表达，替换固定 RAG、强制三段答案、旧结论审核／融合及按模式分流。没有新增 Agent SDK、平台或依赖。
- 模型传输、上下文编排、MemoryStore 事务、界面各自负责一层；聊天和显式 capture 维护共用工具与写入校验，聊天不进入旧 organizer 二次处理。
- 原话先落盘；逻辑输入、活动 attempt、工具操作、参数、结果和原始 checkpoint 持久化。重送／重试复用成功操作，旧 attempt 不能迟到写入。
- 全局召回先利用当前消息、近期意图和指定材料／专题；焦点不限制全局读取。目录与正文证据分开，稳定 ID 可分页读取当前正文、相关历史和会话。
- 长对话真实压缩，摘要／尾部消息／回执成对读取；摘要及首次 checkpoint 都校验回执修订，撤销期间旧上下文不能写回。
- 全文替换只认可产生该工具调用的实际请求中仍可见的完整正文。范围与内容哈希随 checkpoint 保留，旧正文已被预算释放时不能借历史“读过”来覆盖。删除来源在下一请求中清除主正文及附加片段。
- 自动维护保留版本、原话、成员关系和回执；整次撤销先校验所有对象再原子恢复。删除会话后仍能从记忆查来源、回执组和撤销，并显示原会话不可用。
- 主窗／快捷窗／续聊复用统一文字与语音输入，Enter 换行、Command+Enter 发送、停录不自动发送；保留草稿、焦点、来源与同一会话交接。建议点击发送可见原文，保留已有草稿；终态部分回答可手动保存。

内部上界：总上下文 65536 token，输入按 UTF-8 字节作保守估计，总量中预留至少 8192 用于输出；初始上下文 48000 字节，材料 12000、历史 14000、摘要 6000 字节；最多 12 次模型调用、240 秒，建议另限 25 秒。没有新增预算设置页面。
