# UI 精简方案

2026-09-13 · 已授权实施

让记忆正文和主要操作成为视觉重点，减少常驻说明文字。保留现有布局、白黄品牌、阅读排版和统一文字／语音入口。

## 做什么、为什么、怎么做

| 范围 | 为什么改 | 怎么改 |
| --- | --- | --- |
| 侧栏 | 空分组说明、模型状态和存储宣言反复占位，干扰导航。 | 删除三句空分组说明及底部宣言；空置顶、空最近讨论不显示，有内容后出现；保留新建专题入口及记忆页的置顶操作。正常模型状态归入设置，缺少模型或出错时在相关操作处提示。 |
| 通用设置 | 明确的设置名称下面仍附带解释和操作教程。 | 采用“名称＋当前值／控件”的设置行，如“语言［跟随系统］”“登录时启动［开关］”“全局快捷键［⌥M］”。删除页面口号和重复解释，快捷键用法随设置控件按需查看。桌面图标仅控制显示；快捷键可设置／移除，未设置就不注册，删除“暂停快捷入口”。默认 ⌥M 打开快捷窗口、⌥R 录音，录入即生效。两行共用同一快捷键控件；录制、空值、移除及禁用状态保持相同尺寸与对齐。布尔设置统一滑动开关，同类设置行和操作按钮统一间距、字号与高度。仅通用页提供还原默认（语言跟随系统、登录启动与图标开启、两快捷键），不重置其他页。 |
| AI 与语音设置 | 功能介绍、模型说明、状态和页脚层层叠加，夹杂工程细节。 | 首页保留问答与整理、语义检索、语音输入三个独立分组：图标与功能名为主，模型与状态为第二层，设置入口统一靠右，不强制全部单行。详情保留模型选择、下载大小／进度、启停和连接配置；删除“共用模型和草稿规则”等工程措辞。运行细节放入现有折叠区，数据发送说明在选择外部服务时就地显示。 |
| 记忆阅读页 | 正文前有多层状态、归档数量和标签，元信息重复。 | 保留作者与日期单行；去掉工具栏重复的正常阅读状态，保留回收站、输入归档和新版本提示；归档数量只在来源入口显示；标签简化为“正文／来源／历史”，保留原有切换位置。删除“相关记忆”旁的算法解释。输入归档仍需明确标识，不能看起来像可检索的当前记忆。 |
| 讨论与快捷入口 | 统一不同讨论容器的信息层级，避免小窗口重复介绍用途。 | 保留话题标题；主窗眉题与副标题已被样式隐藏，清理重复文案并核查快捷窗等场景，不将其计作主窗新增的视觉改善。引导仅在空对话出现。输入区保留添加记忆、语音、发送及一行快捷键提示；快捷窗仅在附带来源时显示来源项，附加链接／路径入口仍可找到。 |
| 编辑与整理 | 正常操作反复解释版本、原话和草稿机制。 | 用准确状态与按钮表达：“草稿自动保存”“保存”“接受并保存”。整理预览最多保留一句必要说明，详细差异按现有入口查看；冲突、失败或放弃操作时再说明影响和恢复办法。 |

## 统一呈现规则

- 标题和按钮已经说明的事，不再写一遍。简单设置项采用一行，复杂项保留两级信息；隐私与异常说明按实际需要展开。
- 只去掉删除文案留下的多余空白，保留分组间距、控件高度和标题层级，统一设置行对齐。正常设置允许留白，不用更小、更淡的字掩盖拥挤；正文沿用现有排版。
- 空间不足时名称与控件改为上下排列，长模型名允许换行，操作按钮不被挤压；沿用现有窄窗口自适应方式。
- 说明分三种处理：重复与宣传文案删除；低频用法放到明确的展开入口；当前操作必需的信息就地显示。复用现有控件，不另建新手教程系统。
- 图标保留可访问名称及悬停／键盘焦点提示。录音、转写、发送、失败、草稿冲突、外部服务的数据去向和删除／恢复后果，不能只藏在 tooltip 中。
- 保留 AI 修改回执、查看变化、来源和撤销。草稿保存与正文保存明确区分；不改变自动记忆维护、手动保存、原话／版本、输入提交和跨窗口草稿规则。

## 实施与检查

1. 按“侧栏与设置 → 阅读与讨论 → 编辑、整理与异常提示”实施；中英文文案同步调整，复用共享组件和样式。
2. 在常用尺寸及原生最小窗口 760×560 下，同尺寸对比改前改后：检查空库／有内容、模型未配置／已配置、长模型名／标题及中英文界面；正文和主要操作应更突出，常用入口不增加点击层级。
3. 在 macOS 应用检查主窗和快捷窗：提示／菜单不被裁切，键盘与中文输入正常，切换页面不丢草稿、不抢焦点或滚动位置；失败与 AI 修改仍有明确反馈和恢复入口。运行相关 UI 回归、`npm run i18n:check` 和 `npm run build`，将实际结果记入现有 [DEVELOPMENT_PLAN.md](../DEVELOPMENT_PLAN.md)。

本方案仅调整呈现，不新增产品功能，不改变存储和 Agent 执行逻辑；此文件不是实施完成或用户验收记录。
